# Harbor Vector

Native vector companion for Harbor Studio, derived from VectorCraft with the preserved shared-canvas adapter. Maintained for @durtyrobbin.

Clone alongside harbor-paint and harbor-studio; build the Harbor Studio host to use the paint/vector toggle. This repository currently supplies the vector engine and UI, not a separately qualified standalone Harbor Vector installer.

Original project: https://github.com/storytold/vectorcraft. Base commit: 55fdac71fe84a87f08db6625df6ce6c2da556a56. Full history, authorship, MIT/Apache licenses and third-party notices are retained. This is not an official ArtCraft product. Upstream trademark artwork is excluded from the current tree.

Validation and scope: see HARBOR-QUALIFICATION.md.
