# Harbor Vector on Windows

The current qualified Windows entry point is **Harbor Studio**. Install Studio using its per-user Windows setup, then open **Harbor Vector (via Studio)** from the Harbor Start Menu group or desktop. Choose New painting, then Harbor Vector.

Installer source: https://github.com/durtyrobbin/harbor-studio/tree/harbor/main/packaging/harbor

Vector remains a separate source repository. This shortcut is not a standalone Vector executable; it opens the shared Studio host. See HARBOR-QUALIFICATION.md for the current editing and format limits. Studio's installer owns this shortcut and removes it when Studio is uninstalled. User project files are retained.
